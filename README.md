# Job Tracker — трекер заявок на вакансии (Chrome)

## Установка
1. Распакуй архив в постоянную папку (например, Documents/job-tracker). Не удаляй её потом — Chrome загружает расширение прямо оттуда.
2. Открой в Chrome адрес `chrome://extensions`.
3. Справа вверху включи «Режим разработчика» (Developer mode).
4. Нажми «Загрузить распакованное расширение» (Load unpacked) и выбери папку `job-tracker`.
5. Закрепи иконку: значок пазла на панели Chrome → булавка рядом с Job Tracker.

## Как пользоваться
- На LinkedIn, Indeed, Reed, Totaljobs, CV-Library, CWJobs, Glassdoor, jobs.ac.uk нажимаешь «Apply / Easy Apply» — заявка сразу сохраняется, справа появляется окно, где можно поправить поля или отменить.
- На любом другом сайте (например, сайт компании): иконка расширения → «Добавить вакансию с этой страницы».
- Дашборд: иконка → «Открыть дашборд». Там обзор, все заявки, статусы, сравнение офферов, навыки.
- Число на иконке — сколько заявок за последние 7 дней.

## Важно
- Данные хранятся только в этом браузере. Раз в неделю делай «Данные → Скачать копию (JSON)».
- Сайты иногда меняют вёрстку: если поле считалось неточно — поправь его в окне или в карточке заявки, а описание можно вставить вручную и нажать «Пересчитать анализ».
- «Шансы» — ориентир по совпадению навыков, уровню позиции, опыту, графику, правам и допуску. Не прогноз.
- После обновления файлов расширения нажми «Обновить» на chrome://extensions и перезагрузи вкладки с сайтами вакансий.

## Google Таблица (доступ с телефона)
1. Создай новую таблицу: sheets.new.
2. «Расширения» → «Apps Script». Удали код в редакторе, вставь содержимое `google-sheets/Code.gs`, сохрани (Ctrl+S).
3. Выбери функцию `setup` → «Выполнить». Google спросит доступ: «Дополнительно» → «Перейти к проекту (небезопасно)» → «Разрешить». Это твой собственный скрипт, он работает только с этой таблицей.
4. «Развернуть» → «Новое развёртывание» → ⚙ «Веб-приложение». Выполнять от имени: «Я». У кого есть доступ: «Все». «Развернуть» → скопируй ссылку, которая заканчивается на `/exec`.
5. В расширении: «Навыки и настройки» → «Google Таблица» → вставь ссылку и токен (строка `TOKEN` в начале скрипта) → «Проверить подключение» → «Синхронизировать сейчас».

- С телефона меняй «Статус» (выпадающий список), «Заметки», «Следующий шаг», зарплату — расширение заберёт изменения при открытии дашборда и каждые 10 минут, пока Chrome открыт.
- Новую заявку можно добавить прямо в таблице: заполни «Вакансию» и «Компанию» в пустой строке.
- Удаляй заявки в расширении: удалённая в таблице строка вернётся.
- Если поменял код скрипта: «Развернуть» → «Управление развёртываниями» → ✎ → Версия: «Новая версия». Ссылка при этом не изменится.
- Токен — это пароль к твоей таблице. Не публикуй его и ссылку.
